# Parceria Lennon

Projeto de revenda de **iPhones e MacBooks**. Este repositório guarda as pesquisas de mercado, tabelas de preço e materiais da parceria.

## Conteúdo

| Pasta / arquivo | O que tem |
|---|---|
| [`pesquisa-precos/2026-11-iphone.md`](pesquisa-precos/2026-11-iphone.md) | Preços de iPhone 14 ao 18 (todos os modelos) — novembro/2026 |
| [`pesquisa-precos/2026-11-macbook.md`](pesquisa-precos/2026-11-macbook.md) | Preços de MacBook Neo, Air e Pro (novos e seminovos) — novembro/2026 |
| [`pesquisa-precos/2026-11-precos.csv`](pesquisa-precos/2026-11-precos.csv) | Mesmos dados em planilha (abre no Excel / Google Sheets) |

## Como atualizar

Crie um novo arquivo por mês (ex.: `2026-12-iphone.md`) para manter o histórico e comparar a evolução dos preços.
